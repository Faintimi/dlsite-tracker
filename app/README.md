# 同人游戏筛选器（macOS 桌面应用）

**中文** · [English](README_EN.md)

本目录为本项目配套的 macOS 桌面应用源码：读取「dlsite-tracker」管道导出的数据文件（或你自备的 CSV / JSON / 保存的 HTML），在本机筛选、浏览游戏。

**应用界面自身不联网、不采集数据**；数据的采集与更新全部由管道负责（见仓库根 `README.md`）——应用内「开始更新数据」按钮只是在本机启动管道脚本，联网行为全部发生在管道内。

## 构建与运行

```bash
bash scripts/build-app.sh                    # 用 swiftc 构建（仅需 Xcode Command Line Tools）
open "app/dist/同人游戏筛选器.app"            # 启动
```

- 首次打开若被 Gatekeeper 拦截：在 Finder 里**右键 → 打开**（构建为临时签名）
- 构建产物在 `app/dist/`，**不入库**

## 使用

1. 打开应用 → 点「选择数据文件」→ 选择管道的导出文件 `out/works.json`（文件选择框按 ⌘⇧G 可直接粘贴路径）
2. **「开始更新数据」菜单**：**「立即更新热榜（快）」**（约 2–4 分钟：榜单/列表/人气序 → 富化 → 销量 → 导出）与 **「完整维护（同每日计划）」**（含分类人气 / 封面 / 导入续传）；另有 最近 1/3/5/7 年、「自定义年份至今…」、「继续抓更早…」；完成后**自动重读数据**；要求数据文件来自管道项目的 `out/works.json`（应用由该路径推导项目目录来启动对应脚本）
3. **「渐进导入」开关**（P15，侧栏）：开 = 后台启动/续传（范围可选最近一年/三年），关 = 优雅暂停（断点保留可再开）；进行中可「取消导入任务…」（二次确认）；导入完成会自动导出并**自动重读**——开完开关该干嘛干嘛，回来就是全部新作
3. 封面自动显示：`works.json` 中 `image_path` 是相对路径（`covers/<RJ号>.jpg`，相对数据文件所在目录解析）
4. 数据更新后（管道跑完）→ 应用内点「更新」即可重读，**无需重新选择文件**；「更新」实为「**先本地同步导出（纯本机不联网）再重读**」——任何时候点一下都与数据库对齐；非管道项目布局时退回仅重读
5. 左侧筛选：评分 / 销量 / 价格区间 / 作品形式（区间两端包含在内，留空不限）；分类支持**多选**（「包含分类」）与**排除**（「排除分类」，排除优先）；发售年份支持**多选**；**内容标志（P16）**：配音 / 音乐 / 动画 可多选（同时满足）
6. 排序支持：销量 / 评分 / 价格 / **发售时间（新→旧）** / **日热度 / 周热度 / 月热度**（按当前榜位升序，1 = 最热，无榜位排最后）/ 名称
7. 顶部横幅：优先显示**一键更新状态**（数据文件旁 `update-progress.json`：更新中 / 完成 / 中断）；无更新任务时显示**渐进导入进度**（`import-progress.json`：已入库 / 排除非游戏 / 忽略低销旧作 / 剩余）；进行中每 30 秒自动刷新
8. **显示形式（P16/P16.1）**：工具栏切换 大卡列表 / 双列 / 紧凑列表 / 自适应网格 / 封面墙（⌘1–⌘5；记住上次选择）；「个性化」面板可开关 徽章 / 折扣角标+原价划线 / 评价人数
9. **收藏夹与制作者（P17）**：心形 = 加入「我的收藏」；右键 = 加入收藏夹（可新建、可多归属）；侧栏「收藏」区管理收藏夹与关注制作者；点击制作者名 → 该作者全部作品（可关注、可一键跳 DLsite 作者主页看全量）
10. **双击卡片**打开作品页；悬停有高亮提示
11. **启动自动同步（P16）**：若数据文件比本地缓存新（如每日自动更新后），启动即自动「同步导出 + 重读」——打开就是最新
12. **侧栏（P16.1）**：常驻、宽度固定；收起/展开 = 窗口向外扩展/缩回（右侧内容不动；左侧空间不足时尽量左扩、剩余右扩；关闭仅左缘回缩）；带平滑动画
13. **卡片信息（P16.1）**：分类 / 作品形式 / 内容标志 三行平级展示（大卡带行名；中卡分类 3 枚+N 取舍）；形式与标志为醒目彩色胶囊；数据行省字（日期 MM-DD、评分去 /5），窄卡片自动换行不截断

## 数据格式要点

应用读取导出的 `works[]` 数组；`category` 与 `form` 用 `" | "` 分隔；未识别字段直接忽略。

按热度排序使用 `rank_day_current` / `rank_week_current` / `rank_month_current`（**越小越热**，1 = 榜首）与 `rank_trend_current`（官方人气序）。

## 维护

- 应用源码以 `app/DoujinGameFinder.swift` 为准；构建验证：`bash scripts/build-app.sh`
