# Security policy / 安全报告

## Supported versions / 支持范围

Security fixes target the latest published desktop release and the current `main` branch. Older releases may not receive backports.

安全修复以最新发布的桌面版和当前 `main` 分支为目标；旧版本不保证回移修复。

## Report a vulnerability / 报告漏洞

Please use [GitHub's private vulnerability reporting](https://github.com/Faintimi/dlsite-tracker/security/advisories) and select **Report a vulnerability**. Do not post exploit details, credentials, or private data in a public issue. Include the affected version and platform, reproduction steps, and potential impact. The maintainer will coordinate disclosure after assessing and fixing the issue.

请通过 [GitHub 私密漏洞报告](https://github.com/Faintimi/dlsite-tracker/security/advisories) 点击 **Report a vulnerability** 提交。请勿在公开 Issue 中发布利用细节、凭据或私人数据。尽量说明受影响版本与系统、复现步骤和可能影响；维护者会在评估并修复后协调公开。
